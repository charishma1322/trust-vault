# AI Assistance and Prompts

This project was developed with AI assistance for planning, implementation guidance, debugging, and documentation.

## Areas where AI assistance was used
- FastAPI authentication and endpoint implementation guidance
- JWT and password-hashing guidance
- SQLite persistence and audit-chain verification
- Document-sharing and revocation workflow guidance
- PowerShell commands and debugging assistance
- README and threat-model drafting

## Verification
AI-generated suggestions are not proof of correctness. Endpoint behavior, access controls, dependencies, and security claims must be verified by running the application and tests.

## Limitations
The application is a prototype and should not be described as production-secure without further review, automated tests, and deployment hardening.
